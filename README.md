# Zerodha Clone

A full-stack Zerodha Clone built using the MERN Stack.

## Tech Stack
- React
- Node.js
- Express.js
- MongoDB
- Bootstrap / CSS

## Features
- Landing Page
- Dashboard
- Buy/Sell Orders
- Holdings
- Positions
- Authentication
- MongoDB Database

## Installation

### Frontend
```bash
cd frontend
npm install
npm run dev
